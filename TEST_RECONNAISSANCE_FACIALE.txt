🚀 COMMENT TESTER
═════════════════

1️⃣ DÉMARRER LE SERVEUR
───────────────────────

   symfony server:start
   OU
   php -S localhost:8000 -t public/


2️⃣ INSCRIPTION AVEC VISAGE
────────────────────────────

   a) Ouvrez : http://localhost:8000/register
   
   b) Remplissez le formulaire :
      - Nom : Test
      - Prénom : User
      - Email : test@example.com
      - Rôle : admin
      - Mot de passe : password123
   
   c) Dans "Reconnaissance faciale" :
      - Cliquez sur "Configurer maintenant"
      - Autorisez la caméra
      - Attendez "Visage détecté !"
      - Cliquez sur "Capturer mon visage"
      - ✅ Visage capturé !
   
   d) Cliquez sur "S'inscrire"


3️⃣ CONNEXION AVEC VISAGE
──────────────────────────

   a) Ouvrez : http://localhost:8000/admin/login
   
   b) Cliquez sur "Se connecter avec mon visage"
   
   c) Autorisez la caméra
   
   d) Montrez votre visage
   
   e) ✅ Connexion automatique !


4️⃣ CONNEXION CLASSIQUE (TOUJOURS DISPONIBLE)
──────────────────────────────────────────────

   a) Email : test@example.com
   b) Mot de passe : password123
